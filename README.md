
# QualiAgent: Multi-Agent Software Quality Analysis

A research-oriented Python project for evidence-grounded analysis of software-test
quality using a four-agent workflow.

## Implemented agents

1. Repository Context Agent
2. Static Analysis Agent
3. Test Quality Agent
4. Reviewer Agent

The pipeline detects or reasons about:
- flaky-test indicators
- weak assertions
- redundant assertions
- missing test oracles
- excessive test complexity
- outdated testing APIs

Findings include:
- issue type
- severity
- confidence
- traceable evidence
- remediation recommendation
- reviewer decision

## LLM integration

The reviewer and optional single-agent reasoning path support OpenAI-compatible
chat-completions APIs.

Configure environment variables:

```bash
export QUALIAGENT_LLM_BASE_URL="https://api.openai.com/v1"
export QUALIAGENT_LLM_API_KEY="YOUR_KEY"
export QUALIAGENT_LLM_MODEL="YOUR_MODEL"
```

If these are not configured, the full multi-agent project still runs offline using
deterministic evidence-based reviewer logic.

## Install

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Run tests

```bash
pytest -q
```

## Create the reproducible benchmark

```bash
python scripts/generate_benchmark.py
```

This creates exactly:
- 30 benchmark repositories
- 1,500 test cases

## Run multi-agent benchmark analysis

```bash
python scripts/run_benchmark.py
```

## Create the 600-item manual-review sheet

```bash
python scripts/create_manual_review_sample.py
```

This creates `data/manual_review_600.csv`.

## Analyze any local Python repository

```bash
python scripts/analyze_repository.py /path/to/repository
```

## Important resume-claim note

The supplied project structurally supports the planned experiment, but there is an
important distinction:

- `30 repositories / 1,500 tests` generated by the included benchmark are reproducible
  synthetic benchmark repositories.
- If the resume says **"30 open-source Python repositories"**, you should actually run
  the pipeline on 30 public repositories and record their provenance.
- If the resume says **"manually reviewed 600 findings"**, the 600-item review sheet
  must actually be completed.
- Any precision/recall/F1 improvement should come from the completed experiment.

This avoids pre-claiming empirical results that have not yet been measured.
